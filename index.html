ನನ್ನ ಖಾತೆ

ವೇಳಾಪಟ್ಟಿ ತಯಾರಕ ಉಚಿತ

ಇಲಾಖೆಯ 2026–27 ನಮೂನೆಯಂತೆ ಸಮಯ, ವಿಷಯವಾರು ಅವಧಿಗಳು ಮತ್ತು PDF ನಮೂನೆಗಳು. 1) ಸಮಯ → 2) ತರಗತಿಗಳು → 3) ಶಿಕ್ಷಕರು ಮತ್ತು ಅವರು ಕಲಿಸುವ ವಿಷಯ → 4) "ವೇಳಾಪಟ್ಟಿ ತಯಾರಿಸಿ". ಒಬ್ಬ ಶಿಕ್ಷಕರಿಗೆ ಒಂದೇ ಸಮಯದಲ್ಲಿ ಎರಡು ತರಗತಿ ಬರದಂತೆ ತಾನಾಗಿಯೇ ಹಂಚುತ್ತದೆ. ನೀವು ಮಾಡಿದ್ದು ತಾನಾಗಿಯೇ ಉಳಿಯುತ್ತದೆ.

1. ಶಾಲೆಯ ಸಮಯ

ಇಲಾಖೆಯ 2026–27 ವೇಳಾಪಟ್ಟಿಯ ಸಮಯ ಒಂದೇ ಒತ್ತಿನಲ್ಲಿ ಹಾಕಿ (ಬೇಕಾದರೆ ಕೆಳಗೆ ಬದಲಿಸಬಹುದು):

ಸೋಮವಾರ – ಶುಕ್ರವಾರ

ಶನಿವಾರ (ಬೆಳಿಗ್ಗೆ)

2. ಶಾಲೆಯ ತರಗತಿಗಳು

3. ಶಿಕ್ಷಕರು ಮತ್ತು ಅವರು ಕಲಿಸುವುದು

ಹೇಗೆ ತುಂಬುವುದು? (ಉದಾಹರಣೆಗಳು)
  1. ನಲಿಕಲಿ (1–3) ಒಬ್ಬರೇ ಶಿಕ್ಷಕರು: ಅವರ ಹೆಸರಿನ ಕೆಳಗೆ ತರಗತಿ 1, 2, 3 ಒತ್ತಿ → ವಿಷಯ "★ ಎಲ್ಲಾ ವಿಷಯಗಳು" → "ಒಟ್ಟಿಗೆ (ಬಹುವರ್ಗ)" → ಸೇರಿಸಿ.
  2. 4–5 ಒಬ್ಬರೇ ಶಿಕ್ಷಕರು: 4, 5 ಒತ್ತಿ → "★ ಎಲ್ಲಾ ವಿಷಯಗಳು" → "ಒಟ್ಟಿಗೆ" → ಸೇರಿಸಿ. ಬೇರೆ ಬೇರೆ ಶಿಕ್ಷಕರಿದ್ದರೆ ಪ್ರತಿಯೊಬ್ಬರಿಗೆ ಅವರ ತರಗತಿ ಮಾತ್ರ.
  3. 6–8 ವಿಷಯ ಶಿಕ್ಷಕರು: 6, 7, 8 ಒತ್ತಿ → ವಿಷಯ "ಗಣಿತ" → "ಪ್ರತಿ ತರಗತಿಗೆ ಬೇರೆ" → ಸೇರಿಸಿ. ಎರಡನೇ ವಿಷಯ ಇದ್ದರೆ ಮತ್ತೆ ಅದೇ ರೀತಿ ಸೇರಿಸಿ.
  4. ವರ್ಗ ಶಿಕ್ಷಕರು: ಹೆಸರಿನ ಪಕ್ಕ "ವರ್ಗ ಶಿಕ್ಷಕರು" ಆರಿಸಿದರೆ ಪ್ರತಿದಿನ ಆ ತರಗತಿಯ ಮೊದಲ ಅವಧಿ ಅವರದೇ ಆಗುತ್ತದೆ.
  5. ಹೆಸರು ತಪ್ಪಾಗಿದ್ದರೆ ಹೆಸರಿನ ಮೇಲೆಯೇ ತಿದ್ದಿ. ಬೇಡವಾದರೆ "🗑 ತೆಗೆಯಿರಿ" ಒತ್ತಿ.
